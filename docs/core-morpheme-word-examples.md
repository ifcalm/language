# 核心构词要素与代表单词

## 使用说明

本清单不受当前生产词库范围限制，而是从教学价值出发，为核心词根、古典组合形式、前缀和后缀选择关系清晰、较常用的代表单词。

当前版本共包含 **219 个教学条目、825 条构词要素—代表词关系**：61 组拉丁语词根、40 组希腊语词根、16 个常用古典组合形式、46 个前缀条目，以及 56 个派生后缀、专业后缀或屈折词尾条目。组合形式与前缀之间存在少量合理重叠，例如 `hyper-` 和 `tele-`，因此 219 是教学条目数，不是去重后的构词要素数。

- 每个构词要素原则上配置 3–5 个代表词；
- `/` 表示同一构词要素的常见变体；
- 代表词用于观察共同意义，不表示可以把现代词义机械地逐部分直译；
- 同一个单词可能同时用于讲解词根、前缀和后缀；
- 前缀和后缀优先选用现代构词关系清楚的单词，词根部分允许少量具有教学价值的历史关系。

## 常用古典组合形式

这些形式在许多英语教材中也会被称为“词根”，但严格说往往更接近希腊语或拉丁语组合形式。

|---|---|---|
| `auto-` | 自己；自动 | `autobiography`, `automobile`, `automatic`, `autonomy` |
| `hetero-` | 不同 | `heterogeneous`, `heterosexual`, `heteronym` |
| `homo-` | 相同 | `homogeneous`, `homonym`, `homophone` |
| `hyper-` | 超过；过度 | `hyperactive`, `hypertension`, `hypersensitive` |
| `hypo-` | 在下；不足 | `hypothesis`, `hypothermia`, `hypoglycemia` |

| `-ist/-ician` | 专业人员或从业者 | `scientist`, `musician`, `technician` |

## 常用屈折词尾

屈折词尾主要表达语法变化，不生成新的核心词义。

| 词尾 | 语法作用 | 代表单词 |
|---|---|---|
| `-s/-es` | 名词复数或动词第三人称单数 | `books`, `watches`, `runs` |
| `-ed` | 过去式或过去分词 | `walked`, `studied`, `closed` |
| `-ing` | 现在分词或动名词 | `reading`, `running`, `writing` |
| `-er` | 比较级 | `taller`, `faster`, `smaller` |
| `-est` | 最高级 | `tallest`, `fastest`, `smallest` |

## 推荐使用方式

1. 先从每个构词要素选择 3 个最透明的代表词；
2. 让学习者先观察共同部分和共同意义，再给出构词解释；
3. 每组加入一个新词作为猜词练习，但必须结合上下文验证；
4. 前缀、词根、后缀分开学习，熟悉后再进行完整拆解；
5. 对语义变化明显的单词标记为“历史关联”，避免机械翻译。
