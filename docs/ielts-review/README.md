# 雅思词库释义审校(2026-10-30)

对 D1 `ielts_words` 全部 4557 条释义逐条人工审校,按模块分 6 批完成。每批的修改清单(`batch-*.md`)、原始数据(`batch-*.json`)与迁移文件一一对应。

## 审校标准

1. 释义是否准确。
2. 雅思常用义是否缺失、是否排在前面(尤其是写作、学术阅读里的高频义)。
3. 词性是否正确、完整。
4. 近义词是否用了同一个释义而无法区分。
