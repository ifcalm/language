## 三、尚未解决的问题(按影响排序)

### 1. 音标质量:约一半需要重做

| 指标 | 数量 |
|---|---|
| 有音标的词条 | 2180 / 4557 |
| 没有音标和音频 | **2377** |
| 英音中含非词典符号(ɐ、ɹ、ɫ、ɝ) | **902** |
| 美音中含非词典符号(ɹ、ɫ) | 1285 |
| 英音与美音完全相同(多为英音缺失时用美音顶替) | 155 |

现有音标复用自 COCA 词库,来源是 ipa-dict 的宽式转写,和学习者熟悉的词典音标(如 /ɪnˈkriːs/)差别明显。另外,名词和动词重音不同的词(increase、record、present)目前只有一个音标。建议按词典风格统一重做,并在数据结构上支持按词性给音标。

### 2. 释义只做了启发式核对

本次能自动发现的是“明显对不上”的释义。释义是否最贴合雅思语境、多义词的义项排序是否合理,仍需按话题人工抽查。

### 3. 同义词缺少辨析

381 组中文释义相同的词,大多是真同义词,但用户看不出区别(如 hinder / hamper / impede)。建议整理 60–80 组高频易混词的辨析。

### 4. 话题归类未系统核对

每个词只放在一个话题下,个别归类可商榷(如 time-consuming 放在“科技与媒体”)。

### 5. 覆盖率仍有余量

ECDICT 雅思词覆盖 49%、NAWL 72%。剩余缺口主要是派生词(679 个)和 P3 候选(697 个),见 `README.md`。

## 复现

核查脚本按 `README.md` 的方式下载参考数据后运行。核查时使用的 ECDICT 字段为 `translation`(仅用于比对,不复制)和 `pos`。
