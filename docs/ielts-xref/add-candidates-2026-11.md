# 雅思词库待补词清单（2026-11-13）

对象：当前词库 4557 条。本清单只定**收哪些词**，不含释义、例句和音标；你确认范围后，再按以往流程分批写释义和例句、出对比表、写入 D1。

## 依据与筛选标准

- **AWL**：学术词表（Coxhead，570 个词头），数字是子表号，越小越常用。词头取自 EAP Foundation 公开页面，只用于比对。
- **NAWL**、**雅思标签**：沿用本目录 2026-10-28 对比时的数据（NAWL 1.2；ECDICT 的 `ielts` 标签）。
- **词频**：本项目 COCA 词表里的排名，“—”表示在 5536 名之外。
- 建议收的标准：缺的是原形或更常用的形式；或者意思不能从库里已有的同族词直接看出来。
- 不建议单独成条：库里已有短语能覆盖的词（如 `invest in`、`driving licence`）；由已收词规则派生、意思透明的词（如已收 allocate 时的 allocation）。

## 五、基础学术词（需要你先定规则）

这 58 个是 AWL 词头，但很常用（词频多在 1900 名以内），按“纯基础词不收”的现行规则没有收录。问题在于同级别的 policy、process、require、research、major、data 已经在库里，标准并不一致。

area、assume、available、create、individual、issue、respond、role、section、similar、source、specific、category、culture、feature、final、focus、item、normal、previous、primary、seek、text、comment、document、link、partner、physical、publish、remove、sex、task、attitude、civil、code、commit、debate、goal、job、option、aware、contact、image、medical、style、target、version、expert、federal、tape、adult、couple、deny、file、survive、topic、team、vision

建议：纯生活词不收（job、team、couple、sex、tape、adult、partner、item、text、image、style、file、goal，共 13 个），其余 45 个都有明显的学术用法（如 issue 作“议题”、feature 作动词、assume、specific、individual），建议收。
