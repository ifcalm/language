# 核心词根及词库对应单词（v1）

## 使用范围

本清单以 2026-08-25 生产环境 `vocab` 表中的 **5,536 个唯一单词**为范围，整理适合英语词汇学习的高频希腊语、拉丁语词根及其变体。这里只列出当前词库实际收录的对应单词，不补入词库之外的例词。

“核心词根”不是语言学上的封闭集合。本版以 [Reading Rockets 的常用希腊、拉丁词根表](https://www.readingrockets.org/topics/spelling-and-word-study/articles/root-words-suffixes-and-prefixes)为基础，并参考 [American Heritage Dictionary 的印欧词根附录](https://www.ahdictionary.com/word/indoeurop.html)和 [Wikipedia 的希腊、拉丁词根索引](https://en.wikipedia.org/wiki/List_of_Greek_and_Latin_roots_in_English)，补充当前词库中覆盖较高、适合教学的词根。

本版共整理 **86 个核心词根或古典组合形式**、**827 条词根—单词关系**，关联 **803 个不同单词**，占当前词库的 **14.51%**。这里的覆盖率只表示这份核心清单已经明确列出的词，不表示其余单词都没有词根。

统计和阅读时需要注意：

- `/` 分隔的是同一词根在英语中的常见变体，例如 `duc/duct`、`mit/miss`；
- 一个单词可以包含多个构词要素，因此可能出现在不止一个词根下；
- `auto`、`micro`、`tele` 等在不同教材中也会被称为古典组合形式；本清单按常见词根教学口径一并收录；
- 清单按词源关系归类，但词根不一定能直接推出单词的现代词义；
- 已排除大量仅仅拼写相似的词，例如 `fraud` 不属于 `aud`，`former` 不属于表示“形状”的 `form`；
- 本版聚焦词根，不把 `re-`、`un-`、`-tion`、`-able` 等前后缀混入统计。

## 使用建议

这份清单适合先作为内容底稿，而不是直接把整张表一次性展示给学习者。推荐按以下方式使用：

1. 按“当前词库中的关联词数量 × 单词频率”确定学习顺序；
2. 每个词根先选择 3–6 个语义关系最清晰的代表词；
3. 把意义发生明显变化的单词放到“扩展词”中，而不是让学习者机械直译；
4. 单词详情仍保留完整释义、搭配和例句，词根只承担连接与辅助记忆作用；
5. 后续单独整理前缀、后缀，避免把不同类型的构词要素混成一张表。

## 后续校订重点

本版是核心词根底稿，下一轮适合继续补充两类信息：

- 为每个单词标记 `透明`、`部分透明`、`历史关联`，区分其教学价值；
- 补充遗漏但覆盖较高的词根，并对同形异源、经法语进入英语的复杂路径逐项复核。

在完成逐词审核前，本清单不代表 5,536 个单词的全部词根数量，也不应直接作为自动拆词规则。
